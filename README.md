# VoiceTrack Magic

PyQt5 voice-track recorder / processor for radio (silence trimming, FFmpeg filter presets, WAV/MP3,
RadioDJ export, batch mode) with a built-in **SIP phone** (receive/place calls, up to 10 lines,
hold/switch, phonebook, record the call manually).

See `BUILD.md` for building and testing. `SipTest.exe` is a standalone SIP engine test tool.
